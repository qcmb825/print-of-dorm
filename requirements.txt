# 小猫娘打印服务：运行依赖
# Python 3.9 以上就能跑（我开发、部署用的都是 3.11）
# 安装：pip install -r requirements.txt
#
# 数据库直接用标准库的 sqlite3，同步就够用，所以没装 aiosqlite：
# 这项目本来就是低并发的同步 WSGI，上异步数据库只是自找麻烦，也没带来什么好处。

# Web 框架和跨域支持
Flask==3.1.3
Flask-Cors==6.0.5

# 正式跑的时候用这个 WSGI 服务器，不用 Flask 自带的开发服务器（部署细节见 README.md）
waitress==3.0.2

# 密码可逆加密（Fernet 对称加密）。
# 起因是账号管理页要能查看凭据，而哈希没办法还原出明文，
# 所以密码存了两份：password_hash 只用于登录校验，不可逆；
# password_enc 用 Fernet 加密，可逆，只在专设的接口里解密后返回。
cryptography==46.0.3

# QQ 机器人的数据卡渲染（botcard.py 画 PNG）。
# 为什么用 Pillow 而不是「HTML 模板 + 无头浏览器」：后者要拖一个 chromium（约 150MB）
# 进服务器，而我们只需要画几张固定版式的列表卡。Pillow 是普通 wheel，
# Linux / Windows 都有现成的包。
Pillow==12.3.0
